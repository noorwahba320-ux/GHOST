Restore From Backup

Uploading a backup file will replace all current data. A safety copy of the current database is kept automatically.

How it works
  1. Click Download Data File regularly (e.g. weekly) and keep it somewhere safe.
  2. If you set up the panel on a new server, deploy the app first without changing any data.
  3. Log in as admin, come back to this page, and upload the saved file under Restore From Backup.
  4. Restart the app service so every connection picks up the restored data.
